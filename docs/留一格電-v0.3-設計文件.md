## 2. 研究：點解揀咗嘅設定會失真

### 2.1 真實情況

- 香港約有 36 萬名外傭，大約照顧八分一家庭（China Daily，2025 年 10 月）。
- 有 12 歲或以下小朋友嘅家庭，32.5% 有請家傭（統計處主題性住戶統計調查第 72 號）。
- 研究發現，請咗住家工人嘅在職父母做家務嘅時間少咗。媽媽將家務同日常照顧交畀姐姐，自己集中做情感連結同小朋友發展相關嘅事（浸會大學研究）。
- 有啲媽媽擔心小朋友同姐姐太親，會蓋過自己同小朋友嘅關係（Ip 等人，2008）。
- 媽媽報告過嘅真實情況：小朋友跌親撲去姐姐度而唔係搵媽媽；姐姐用自己嘅方法管教，同媽媽定落嘅規矩唔同。
- 外傭規定最低工資由 2026 年 10 月 3 日起加到 $5,220。

### 2.2 v0.2 有咩失真

| 設定 | 失真位 |
|---|---|
| 有姐姐 | 成局得 3 張卡同姐姐有關。其餘時間你照樣自己洗衫、執屋、買餸、煮飯。真實有姐姐，壓力會轉咗去「管理」同「心痛」 |
| 冇姐姐 | 「叫姐姐」自動變「叫外婆」，即係假設個個都有外婆幫手 |
| 返工媽媽 | 下晝 3:30 照出「陪佢去公園」呢類卡，但你人喺公司 |
| 在家工作 | 得 2 張專屬卡 |
| 新手BB＋返工 | 冇返工泵奶、BB唔肯飲奶樽呢類真實場面 |
| 老公 | 只係一個求助名，次次都成功 |

### 2.3 v0.3 點改

- 開場分開問兩條：「有冇請姐姐？」「有冇長輩幫手湊？」。四種家庭組合各有自己嘅卡。
- **有姐姐**：家務卡換成管理卡。
  - 「姐姐煮嘅好食過你」
  - 姐姐追住餵飯
  - 「收咗喺安全地方」
  - 碌電話
  - 續約同加人工
  - 跌親搵姐姐
  - CCTV
  - 外婆同姐姐鬥氣
  - 夜晚同姐姐交代聽日嘅嘢
  - 另外：星期四有機會「姐姐病咗」，星期日佢放假。姐姐每日最多幫 3 次。
- **冇姐姐**：買餸、抹地、洗廁所、清雪櫃、洗碗、摺衫、週末大執，全部自己嚟。
- **有長輩**：外婆送薯片相、外婆煮飯順便講你、星期日返外婆屋企。外婆每日最多幫 2 次，幫完有一半機會順便講兩句。
- **兩邊都冇**：託管中心提早閂門呢類卡。救命每日多一次。
- **返工媽媽**：日頭係工作卡，加「屋企打嚟」卡，例如學校話發燒要接、補習社話佢冇去、屋企 send 片話BB唔肯飲奶樽。放工返屋企之後先開始第二份工。
- **在家工作**：4 張專屬卡，例如「媽咪我要屙屎！」全部人都聽到、mute 住講咗五分鐘。

## 3. 每日一局

- 朝早由 100% 開始。如果昨晚斷電，就由 90% 開始。
- 每日大約 8 至 10 件事，跟你嘅設定排：

| 返工 | 在家工作 | 全職 |
|---|---|---|
| 07:00 朝早 | 07:00 朝早 | 07:00 朝早 |
| 09:30 返工 | 09:30 開會 | 09:30 家務 |
| 13:00 午飯叉電 | 11:30 家務 | 11:30 家務 |
| 15:30 屋企打嚟 | 13:00 午飯叉電 | 13:00 午飯叉電 |

| 21:30 細路瞓咗之後 | 20:36 瞓覺前、21:30 夜晚 | 20:36 瞓覺前、21:30 夜晚 |

- 每日仲會加插：
  - 星期二：家婆 WhatsApp

- **輸**：
  - 日頭跌到 0%，即刻斷電。
  - 或者 22:00 唔夠 20%。

## 4. 救命同老公

### 4.1 卡上面嘅「救命」

揀邊個嚟幫手。每個人都會顯示成功率。

| 隊友 | 成功率 | 限制 |
|---|---|---|
| 老公 | 25% ＋ 隊友值 × 0.5%（最高約 75%） | 返緊工時，只可以做遙距嘢 |
| 姐姐 | 90% | 每日 3 次；星期日同病咗嗰日冇 |
| 外婆 | 85% | 每日 2 次；一半機會順便講兩句（−2%） |
| 外援（同事、朋友、姑娘、老師） | 85% | 冇 |

**老公嘅三種結果**

- 成功：唔扣電，隊友值 +4。
- 做一半：−3%，隊友值 +3。
- 失敗：−4%，要揀過另一個方法，但隊友值都會 +2。佢學緊嘢。

老公失敗時會講藉口，例如：
- 「等陣，我屙緊屎。」（已經屙咗四十分鐘。）
- 「你做開嘛。」
- 「佢要媽媽㗎嘛。」

### 4.2 主畫面嘅「救命！」大掣

每日 2 次。冇姐姐又冇長輩嘅家庭，每日 3 次。

- 救命呀老公！幫我湊半個鐘：+8%
- 打畀外婆、叫姐姐帶落街：+6%
- 打畀好朋友呻兩句：+4%
- WhatsApp 老公「我冇電喇」：會真係打開 WhatsApp send 出去。廣東話同英文用 WhatsApp，台灣版用 LINE，大陸版用系統分享。

### 4.3 隊友值

- 開局 28 至 37。
- 你叫得多，佢就學得多。到 80 會有勳章「訓練出神隊友」。
- 低過 40：屋企每件事多用 2%（「老公攤喺梳化」）。
- 70 或以上：每件事少用 2%（「老公有幫手」）。
- 60 或以上：可能出現「神隊友時刻」，佢主動洗碗（+6%）。

## 5. 其他規則

- **自己做**：基本電 × 1.8。BB嘅事喺你低過 40% 時再 +5%，而且有 45% 機會爆煲，要修補三步。
- **放手**：基本電 +2%（放手都要用少少力）。部分會開背景擔心。
- **延遲**：0%，推後少少或者推去聽日。部分會開擔心。
- **背景擔心**：每個鐘 −1%。可以咁樣關：
  - 換個講法：−4%
  - 變成行動：−3 至 −4%
  - 交畀人：0%
- **把聲反彈**：每句 −5%。
- **叉電**：小遊戲玩完先加電，加 +4 至 +8%。
- **用你嘅 20%**：用嘅時候會問你一次。

## 6. 勝率測試

用自動玩家喺真遊戲入面玩，跑齊 48 種設定（4 個年齡 × 3 種工作 × 有冇姐姐 × 有冇長輩）。

| 玩法 | 每日勝率 |
|---|---|
| 一般玩家（混合揀，有時求救、有時關擔心） | **約 65%**（兩次測試：65%、68%） |
| 樣樣自己做、唔求救 | 0% |
| 亂揀 | 約 35% |
| 識放手、識求救、識關擔心 | 約 100% |

唔同家庭有少少分別：有姐姐又有長輩嘅返工媽媽最易（約 80%），冇姐姐又冇長輩嘅全職媽媽最難（約 55%），同現實一樣。

即係話：學識用救命同放手，就會贏。一般人第一次玩，大概三日贏兩日。

## 7. 晚上

**贏**
1. 容光煥發：全屋亮燈、媽媽發光，BB講一句童語。老公隊友值 50 以上，佢仲會讚你靚。
2. 一朵內疚雲：每晚得一朵，跟當日發生嘅事揀，一個星期唔會重複。例如今日求過救，就係「叫人幫手好麻煩人」。
3. 用你嘅 20%：陪細個嘅自己（贏兩晚之後解鎖）、七款放空室遊戲、沖涼、早啲瞓。
4. 今晚嘅金句。
5. 第 N 日打卡圖。

**輸**
1. 斷電：黑燈，「斷電」兩隻字閃。
2. 媽媽大叫，小朋友有反應，每個年齡唔同。例如幼稚園：「我講咗幾多次！你再係咁我唔理你㗎喇！」
3. 「你唔係壞媽媽。你係冇咗電。」
4. 攬住佢講對唔住，小朋友回應。例如中學：門隙塞咗張紙出嚟：「我都有錯。早唞。」
5. 金句同打卡圖。

**第 6、7 日彩蛋**：如果你贏咗 3 日以上、求救 3 次以上，BB會問你：「媽咪，你今日點呀？」

**星期日完**：
- 結局稱號：需要叉電嘅／撐得住嘅／容光煥發嘅／發光嘅媽媽。
- 老公稱號：梳化隊友／學緊嘢嘅隊友／神隊友。
- 一星期打卡圖。

## 8. 打卡區同人數計算

- 位置：主畫面「打卡」，或者選單。

### 8.2 人數計算
- 用免費、唔使登記嘅 Abacus 計數服務。只會喺正式網站計。
- 計五樣：
  - 媽媽人數（每部手機計一次）
  - 開咗幾多局
  - 玩完幾多日
  - 幾多日容光煥發
  - 整咗幾多張打卡圖
- 唔收集任何個人資料。
- 過咗 10,000 個媽媽，標題頁先會公開顯示「已經有 N 個媽媽玩過」。
- **你自己點睇**：選單 → 關於呢個遊戲 → 連撳底部版本號 5 下 → 輸入密碼 **katy10000**。
