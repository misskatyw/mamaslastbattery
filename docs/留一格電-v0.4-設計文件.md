# 留一格電 v0.4 · 設計文件

## 今次改咗乜

| 項目 | 做法 |
|---|---|
| 開始之前 | 一頁過，揀完唔會跳。問：點稱呼、小朋友幾大（新增 1 至 3 歲幼兒）、有冇返工、有冇人幫手湊，最尾先問「你同另一半一齊生活嗎？」。揀「冇」嘅話，成個遊戲都唔會出現老公：冇老公角色、冇老公事件、冇隊友值，求助改搵朋友，打卡卡同訊息都改做「分享畀朋友」。 |
| 幫手 | 刪走奶奶、外婆、工人姐姐，改做一個「幫手」（屋企人、朋友都算）。佢哋嘅專屬事件、聲音同對白都拎走。 |
| 老公體驗模式 | 首頁「👨 老公體驗模式：做一日媽媽」。老公用媽媽身份玩一日（星期三），湊仔、家務、擔心全部照計。完咗有「你體驗咗老婆嘅一日」結果頁、五個今晚點幫佢叉電嘅方法，可以 send 俾老婆：「今晚碗我洗，你休息吓」。呢個模式唔會蓋過老婆部機嘅存檔。 |
| 五日版 | 星期三至日，保留週末。五日結果卡改做五格。 |
| 求助 | 「救命」改名做「求助」。熱線頁改名做「求助熱線」。 |
| 字眼 | 規則改做「瞓覺前仲有 20% 電，你就贏。電量跌到 0%，媽媽就會攰到頂唔順，我哋叫佢做『斷電』」。 |
| 輸咗 | 「今日你攰到頂唔順，大聲咗。」→「你已經做得夠好。一個咁攰都仲撐住嘅媽媽，已經好努力。」→「小朋友永遠都愛你。攬住佢、講句對唔住，你哋嘅關係就會駁返。」修補頁加安全圈提示。 |
| 安全圈（融入遊戲） | 同小朋友有關嘅事件標「上半圈・探索」「下半圈・安慰」「雙手・帶領」，㩒標籤彈出佢呢刻嘅需要同貼士；揀完多一句回饋；每晚結算「今日安全圈：陪佢探索 X・接住佢 Y・溫柔帶領 Z」；爆咗之後嘅修補；五日結局總結三個數字。 |
| 背後嘅理論 | 選單入面，只講安全圈同鏡像神經元（講明鏡像神經元仲有科學爭議）。 |
| 留多過一格電 | 寫入首頁簡介、結局頁同金句。 |
| 金句 | 用 Katy 揀嘅 50 句。冇老公模式會收埋「神隊友」嗰句。 |
| 介面 | 上面嘅屋仔、電量卡同工具列縮細；下面事件卡嘅字同選擇掣放大。 |
| 微信 | 简体版「傳微信」只會複製訊息，提示去微信貼上。 |
| 頂走把聲 | 把聲飛得快一倍，一句接一句，愈後愈快，左右搖得更大。 |
| 書面語 | 繁體同简体全部用書面語；以前用廣東話儲低嘅金句同童言，轉語言後會自動換返該語言版本。 |
| 創作者連結 | 首頁同關於頁有 Instagram @misskw3_3 同 Katy 個人網站掣。 |
| 靜觀錄音 | 廣東話用原本錄音；英文用英文錄音；繁體同简体用普通話錄音，字幕對準錄音。 |
| 語言 | 次序：繁體中文、廣東話、简体中文、English，只寫語言名。第一次打開按手機時區估語言。 |
| 求助熱線地區 | 用電話國際區號：+852、+886、+86、其他地方。熱線說明唔提政府部門名。 |
